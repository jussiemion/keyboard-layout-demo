## Pierwsze znaki

**Potem** oznacza naciśnięcie i zwolnienie przed kolejną literą; **+** —
przytrzymanie razem. Oznaczenia odpowiadają fizycznym pozycjom US QWERTY. Na
macOS <kbd>Alt</kbd> to <kbd>Option</kbd>.

| Naciśnij                                                 | Wynik |   Tryb   |
| -------------------------------------------------------- | :---: | :------: |
| <kbd>Alt</kbd>, potem <kbd>C</kbd>                       |  `©`  | **`M1`** |
| <kbd>Alt</kbd>, potem <kbd>Alt</kbd>, potem <kbd>C</kbd> |  `¢`  | **`M2`** |
| <kbd>Alt</kbd> + <kbd>-</kbd>                            |  `—`  | **`M0`** |
| <kbd>Alt</kbd> + <kbd>/</kbd>                            |  `…`  | **`M0`** |
| <kbd>Alt</kbd> + <kbd>,</kbd>                            |  `«`  | **`M0`** |
| <kbd>Alt</kbd> + <kbd>.</kbd>                            |  `»`  | **`M0`** |

**`S` — Switcher**: przełącznik języka (**`S0`–`S4`**). **`M` — Modifier**:
modyfikator przełączający tryby pisania (**`M0`–`M2`**).

**`M0`** to zwykłe pisanie. **`M1`** i **`M2`** wybierają warstwę symboli dla
następnego wpisu. Nie ma limitu czasu między naciśnięciami. <kbd>Esc</kbd>
anuluje oczekujący znak lub akcent.

> [!TIP]
>
> **Menu → Samouczek** prowadzi przez krótkie ćwiczenia. Wprowadzenie do
> [układu Birmana](https://ilyabirman.ru/typography-layout/) i test końcowy
> można pominąć. Przycisk z książką otwiera ściągawkę.

## Znaki diakrytyczne

Wpisz literę i zwolnij ją, potem naciskaj i zwalniaj <kbd>Shift</kbd>:
`a → ą → a`, `z → ż → ź → z`. Przytrzymany z literą <kbd>Shift</kbd> działa
zwyczajnie. Polskie litery są też dostępne przez <kbd>Alt</kbd> z odpowiednią
literą.

Akcent ostry: kolejno <kbd>Alt</kbd>, <kbd>Alt</kbd>, <kbd>/</kbd>, samogłoska.
Hebrajski używa prawego <kbd>Alt</kbd> do niqqud, arabski — przytrzymanego
<kbd>Shift</kbd> do znaków samogłoskowych; nie mają cyklu po literze.

## Języki i ustawienia

|   Slot   | Naciśnij                            | Wynik                                   |
| :------: | ----------------------------------- | --------------------------------------- |
| **`S0`** | <kbd>Caps Lock</kbd>                | Przełącz między dwoma głównymi językami |
| **`S1`** | <kbd>Caps Lock</kbd> + <kbd>J</kbd> | Przypisany język 1                      |
| **`S2`** | <kbd>Caps Lock</kbd> + <kbd>K</kbd> | Przypisany język 2                      |
| **`S3`** | <kbd>Caps Lock</kbd> + <kbd>L</kbd> | Przypisany język 3                      |
| **`S4`** | <kbd>Caps Lock</kbd> + <kbd>;</kbd> | Przypisany język 4                      |

W **Menu → Ustawienia** przypisz sześć języków i **zapisz**. Para **`S0`** musi
zawierać dwa różne warianty; pozostałe miejsca mogą się powtarzać.

Zmiana języka **interfejsu** wybiera też jego klawiaturę. Selektor **nad
klawiaturą** zmienia tylko klawiaturę. Nie zmieniają języka systemu ani
istniejącego tekstu.

Naciśnij oba <kbd>Ctrl</kbd> razem i zwolnij, aby przełączyć typografię demo.
<kbd>Caps Lock</kbd> nadal zmienia języki.

## Wyszukiwanie i wygląd

Lupa, <kbd>Ctrl</kbd> + <kbd>F</kbd> otwierają wyszukiwanie. Wpisz nazwę, znak,
`U+0024`, język lub kraj. Drobne literówki są tolerowane; karta objaśnia
wpisywanie i użycie.

Menu pozwala wybrać jasny lub ciemny motyw. Linux/Windows/macOS zmienia wygląd
klawiatury, nie układ systemowy.

Tekst i zapytania nie są zapisywane ani wysyłane przez aplikację. Ustawienia
pozostają w przeglądarce; czcionki są dołączone do strony.
