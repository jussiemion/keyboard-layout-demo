## Первые символы

**Затем** — нажать и отпустить перед следующей клавишей. **+** — удерживать
вместе. Обозначения соответствуют физическим позициям US QWERTY; на macOS
<kbd>Alt</kbd> — это <kbd>Option</kbd>.

| Нажмите                                                  | Результат |  Режим   |
| -------------------------------------------------------- | :-------: | :------: |
| <kbd>Alt</kbd>, затем <kbd>C</kbd>                       |    `©`    | **`M1`** |
| <kbd>Alt</kbd>, затем <kbd>Alt</kbd>, затем <kbd>C</kbd> |    `¢`    | **`M2`** |
| <kbd>Alt</kbd> + <kbd>-</kbd>                            |    `—`    | **`M0`** |
| <kbd>Alt</kbd> + <kbd>/</kbd>                            |    `…`    | **`M0`** |
| <kbd>Alt</kbd> + <kbd>,</kbd>                            |    `«`    | **`M0`** |
| <kbd>Alt</kbd> + <kbd>.</kbd>                            |    `»`    | **`M0`** |

**`S` — Switcher**: переключатель языка (**`S0`–`S4`**). **`M` — Modifier**:
модификатор, переключающий режимы ввода (**`M0`–`M2`**).

**`M0`** — обычный ввод. **`M1`** и **`M2`** выбирают слой символов для
следующего ввода. Таймера между нажатиями нет. <kbd>Esc</kbd> отменяет ожидающий
символ или акцент.

> [!TIP]
>
> **Меню → Обучающий тур**: короткие упражнения, пропуск введения в
> [раскладку Бирмана](https://ilyabirman.ru/typography-layout/) и необязательный
> финальный тест. Кнопка с книгой открывает шпаргалку.

## Диакритика

Введите букву и отпустите её, затем нажимайте и отпускайте <kbd>Shift</kbd>:
русский `е → ё → е`, польский `a → ą → a`, немецкий `u → ü → u`. Удержание
<kbd>Shift</kbd> с буквой работает как обычно.

Для ударения нажмите по очереди <kbd>Alt</kbd>, <kbd>Alt</kbd>, <kbd>/</kbd>,
затем гласную. В иврите огласовки вводятся через правый <kbd>Alt</kbd>, в
арабском — через удерживаемый <kbd>Shift</kbd>; перебора после буквы у них нет.

## Языки и настройки

|   Слот   | Нажмите                             | Результат                      |
| :------: | ----------------------------------- | ------------------------------ |
| **`S0`** | <kbd>Caps Lock</kbd>                | Переключить два основных языка |
| **`S1`** | <kbd>Caps Lock</kbd> + <kbd>J</kbd> | Назначенный язык 1             |
| **`S2`** | <kbd>Caps Lock</kbd> + <kbd>K</kbd> | Назначенный язык 2             |
| **`S3`** | <kbd>Caps Lock</kbd> + <kbd>L</kbd> | Назначенный язык 3             |
| **`S4`** | <kbd>Caps Lock</kbd> + <kbd>;</kbd> | Назначенный язык 4             |

В **Меню → Настройки** назначьте все шесть языков и нажмите **Сохранить**. В
паре **`S0`** нужны два разных варианта; остальные назначения могут повторяться.

Выбор языка **интерфейса** меняет и основную карту клавиатуры. Селектор **над
клавиатурой** меняет только клавиатуру. Язык ОС и введённый текст не меняются.

Нажмите оба <kbd>Ctrl</kbd> вместе и отпустите, чтобы включить или выключить
типографику демо. <kbd>Caps Lock</kbd> продолжит переключать языки.

## Поиск и оформление

Лупа, <kbd>Ctrl</kbd> + <kbd>F</kbd> открывают поиск. Введите название, символ,
`U+0024`, язык или страну. Небольшие опечатки допустимы; карточка объясняет ввод
и употребление.

- **Найти символ:** <kbd dir="ltr">Ctrl</kbd> + <kbd dir="ltr">F</kbd> /
  <kbd dir="ltr">Caps Lock</kbd> + <kbd dir="ltr">F</kbd>.
- **Шпаргалка:** <kbd dir="ltr">Ctrl</kbd> + <kbd dir="ltr">H</kbd> /
  <kbd dir="ltr">Caps Lock</kbd> + <kbd dir="ltr">H</kbd>.

В меню доступны светлая и тёмная темы. Селектор Linux/Windows/macOS меняет вид
клавиатуры, а не раскладку ОС.

Приложение не сохраняет и не отправляет введённый текст и поисковые запросы.
Настройки остаются в браузере; шрифты входят в сайт.
