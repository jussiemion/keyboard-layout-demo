## الرموز الأولى

في التسلسل، اترك <kbd dir="ltr">Alt</kbd> قبل ضغط المفتاح التالي. تعني علامة `+`
الضغط معًا. في macOS استخدم <kbd dir="ltr">Option</kbd> بدلًا من
<kbd dir="ltr">Alt</kbd>. تشير أسماء الحروف إلى مواضع QWERTY الفعلية، حتى عندما
تتغير تسميات المفاتيح حسب اللغة.

| اضغط                                                                                                    |          النتيجة           |  الوضع   |
| ------------------------------------------------------------------------------------------------------- | :------------------------: | :------: |
| <span dir="ltr"><kbd dir="ltr">Alt</kbd>, ثم <kbd dir="ltr">C</kbd></span>                              | <span dir="ltr">`©`</span> | **`M1`** |
| <span dir="ltr"><kbd dir="ltr">Alt</kbd>, ثم <kbd dir="ltr">Alt</kbd>, ثم <kbd dir="ltr">C</kbd></span> | <span dir="ltr">`¢`</span> | **`M2`** |
| <span dir="ltr"><kbd dir="ltr">Alt</kbd> + <kbd dir="ltr">-</kbd></span>                                | <span dir="ltr">`—`</span> | **`M0`** |
| <span dir="ltr"><kbd dir="ltr">Alt</kbd> + <kbd dir="ltr">/</kbd></span>                                | <span dir="ltr">`…`</span> | **`M0`** |
| <span dir="ltr"><kbd dir="ltr">Alt</kbd> + <kbd dir="ltr">,</kbd></span>                                | <span dir="ltr">`«`</span> | **`M0`** |
| <span dir="ltr"><kbd dir="ltr">Alt</kbd> + <kbd dir="ltr">.</kbd></span>                                | <span dir="ltr">`»`</span> | **`M0`** |

**`S` — Switcher**: مبدّل اللغة (**`S0`–`S4`**). **`M` — Modifier**: معدِّل
يغيّر وضع الكتابة (**`M0`–`M2`**).

**`M0`** للكتابة العادية؛ ويختار **`M1`** و**`M2`** طبقة رموز للإدخال التالي. لا
حد زمني بين الضغطات. يلغي <kbd dir="ltr">Esc</kbd> رمزًا أو علامة منتظرة. تتيح
أزرار `M0`/`M1`/`M2` فوق لوحة المفاتيح اختيار الوضع أيضًا.

## الحروف والعلامات

تستخدم الخريطة العربية المرجع **XKB `ara(basic)`**. الحروف في الطبقة الأساسية،
وعلامات التشكيل على <kbd dir="ltr">Shift</kbd>.

العربية لغة من اليمين إلى اليسار في الواجهة وحقل النص، بينما تظل مواضع المفاتيح
الفعلية بترتيبها المعتاد. الخط العربي مرفق بالموقع مع دعم وصل الحروف والعلامات.

لا يوجد للعربية أو العبرية تبديل علامات بالضغط على <kbd dir="ltr">Shift</kbd>
بعد الحرف. للتشكيل العربي اكتب الحرف ثم علامته على طبقة
<kbd dir="ltr">Shift</kbd>؛ ويستخدم النيْقود العبري <kbd dir="ltr">Alt</kbd>
الأيمن بعد الحرف.

## اللغات والإعدادات

|  الخانة  | اضغط                                                                           | النتيجة                    |
| :------: | ------------------------------------------------------------------------------ | -------------------------- |
| **`S0`** | <kbd dir="ltr">Caps Lock</kbd>                                                 | التبديل بين لغتين أساسيتين |
| **`S1`** | <span dir="ltr"><kbd dir="ltr">Caps Lock</kbd> + <kbd dir="ltr">J</kbd></span> | اللغة المعيّنة 1           |
| **`S2`** | <span dir="ltr"><kbd dir="ltr">Caps Lock</kbd> + <kbd dir="ltr">K</kbd></span> | اللغة المعيّنة 2           |
| **`S3`** | <span dir="ltr"><kbd dir="ltr">Caps Lock</kbd> + <kbd dir="ltr">L</kbd></span> | اللغة المعيّنة 3           |
| **`S4`** | <span dir="ltr"><kbd dir="ltr">Caps Lock</kbd> + <kbd dir="ltr">;</kbd></span> | اللغة المعيّنة 4           |

عيّن اللغات الست في **القائمة ← الإعدادات** ثم **احفظ**. يجب أن يختلف خيارا
**`S0`**؛ يمكن تكرار البقية. اختيار لغة **الواجهة** يختار لوحة مفاتيحها أيضًا.
المحدد **فوق لوحة المفاتيح** يغيّر اللوحة وحدها، دون تغيير لغة النظام أو النص
السابق.

اضغط مفتاحَي <kbd dir="ltr">Ctrl</kbd> معًا ثم اتركهما لتشغيل الطباعة الخاصة أو
إيقافها. يبقى <kbd dir="ltr">Caps Lock</kbd> لتبديل اللغات.

<details>
<summary>جميع الخيارات</summary>

تتوفر الواجهة ووثائق المستخدم بـ **14 لغة**، ولوحة المفاتيح بـ **24 خيارًا**.
اللغات هي الإنجليزية والروسية والبولندية والفرنسية والألمانية والإسبانية
والبرتغالية والإيطالية والرومانية والعبرية والعربية والتركية والفيتنامية
والهولندية.

تستخدم الخيارات الإنجليزية لأستراليا ونيجيريا ونيوزيلندا وسنغافورة والولايات
المتحدة وزيمبابوي خريطة US QWERTY نفسها. تستخدم الإسبانية المكسيكية خريطة أمريكا
اللاتينية، والبرتغالية البرازيلية ABNT2، والفرنسية الكندية خريطة كندا الفرنسية،
والألمانية السويسرية QWERTZ السويسرية. هذه خيارات للوحة المفاتيح، وليست ترجمات
مستقلة للواجهة.

## البحث والمظهر

تفتح العدسة أو <kbd dir="ltr">Ctrl</kbd> + <kbd dir="ltr">F</kbd> البحث عن
الرموز. ابحث بالاسم أو الرمز أو كود مثل `U+0024` أو اللغة أو الدولة. يعمل البحث
باللغات الأربع عشرة ويتحمّل الأخطاء الكتابية الصغيرة.

- **البحث عن رمز:** <kbd dir="ltr">Ctrl</kbd> + <kbd dir="ltr">F</kbd> /
  <kbd dir="ltr">Caps Lock</kbd> + <kbd dir="ltr">F</kbd>.
- **ورقة مرجعية:** <kbd dir="ltr">Ctrl</kbd> + <kbd dir="ltr">H</kbd> /
  <kbd dir="ltr">Caps Lock</kbd> + <kbd dir="ltr">H</kbd>.

تتيح القائمة المظهر الفاتح والداكن. يغيّر Linux/Windows/macOS شكل لوحة المفاتيح،
لا تخطيط النظام.

لا يحفظ التطبيق نص التدريب أو استعلامات البحث ولا يرسلها. تبقى التفضيلات في
المتصفح، والخطوط مرفقة بالموقع.
