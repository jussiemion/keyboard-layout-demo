Prueba símbolos tipográficos, acentos y cambios de idioma en el navegador, sin
instalar nada ni crear una cuenta. Puedes escribir con el teclado físico o
pulsar las teclas en pantalla.

## Primeros caracteres

En las secuencias, suelta <kbd>Alt</kbd> antes de la siguiente tecla. El signo +
indica teclas mantenidas a la vez. En macOS, utiliza <kbd>Option</kbd> en lugar
de <kbd>Alt</kbd>. Las letras designan posiciones físicas, aunque las etiquetas
cambien según el idioma.

| Pulsa                                                        | Resultado |   Modo   |
| ------------------------------------------------------------ | :-------: | :------: |
| <kbd>Alt</kbd>, después <kbd>C</kbd>                         |    `©`    | **`M1`** |
| <kbd>Alt</kbd>, después <kbd>Alt</kbd>, después <kbd>C</kbd> |    `¢`    | **`M2`** |
| <kbd>Alt</kbd> + <kbd>-</kbd>                                |    `—`    | **`M0`** |
| <kbd>Alt</kbd> + <kbd>/</kbd>                                |    `…`    | **`M0`** |
| <kbd>Alt</kbd> + <kbd>,</kbd>                                |    `«`    | **`M0`** |
| <kbd>Alt</kbd> + <kbd>.</kbd>                                |    `»`    | **`M0`** |

**`M0`** es escritura normal; **`M1`** y **`M2`** eligen una capa de símbolos
para la siguiente entrada. No hay límite de tiempo entre pulsaciones.
<kbd>Esc</kbd> cancela el símbolo o acento pendiente. También puedes elegir
`M0`/`M1`/`M2` encima del teclado.

>
> El menú ofrece un **recorrido guiado** con ejercicios breves. Si ya conoces la

## Acentos

El español utiliza la distribución de referencia de España. Cambiar la
plataforma visual no la sustituye por variantes nacionales de Windows o macOS.

Escribe y suelta una letra; después pulsa y suelta <kbd>Shift</kbd> para
recorrer sus variantes: `a → á → a`, `n → ñ → n`, `u → ú → ü → u`. Funcionan
ambos <kbd>Shift</kbd>, tanto físicos como en pantalla.

<kbd>Alt</kbd>, <kbd>Alt</kbd> y la posición física de <kbd>/</kbd> preparan un
acento agudo para la siguiente letra.

## Idiomas y ajustes

| Posición | Pulsa                               | Resultado                              |
| :------: | ----------------------------------- | -------------------------------------- |
| **`S0`** | <kbd>Caps Lock</kbd>                | Alternar entre dos idiomas principales |
| **`S1`** | <kbd>Caps Lock</kbd> + <kbd>J</kbd> | Idioma asignado 1                      |
| **`S2`** | <kbd>Caps Lock</kbd> + <kbd>K</kbd> | Idioma asignado 2                      |
| **`S3`** | <kbd>Caps Lock</kbd> + <kbd>L</kbd> | Idioma asignado 3                      |
| **`S4`** | <kbd>Caps Lock</kbd> + <kbd>;</kbd> | Idioma asignado 4                      |

Asigna los seis idiomas en **Menú → Ajustes** y **guarda**. Las dos opciones de
**`S0`** deben ser distintas; las demás pueden repetirse. Elegir el idioma de la
**interfaz** también elige su teclado. El selector **sobre el teclado** solo
cambia el teclado; no modifica el idioma del sistema ni el texto.

Mantén ambos <kbd>Ctrl</kbd> y suéltalos para activar o desactivar la
tipografía. <kbd>Caps Lock</kbd> sigue cambiando de idioma.

## Búsqueda y apariencia

La lupa, <kbd>Ctrl</kbd> + <kbd>F</kbd> abren la búsqueda local. Busca por
nombre, carácter, código como `U+0024`, idioma o país. Se consultan los catorce
idiomas y se toleran pequeñas erratas.

El menú ofrece temas claro y oscuro. Linux/Windows/macOS cambia la apariencia
del teclado, no la distribución del sistema.

La aplicación no guarda ni transmite el texto de práctica o las consultas. Las
preferencias permanecen en el navegador; las fuentes están incluidas en el
sitio.
