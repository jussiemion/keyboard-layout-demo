# Disposição tipográfica de Semyon Yushkevich

**[Abrir a demonstração](https://jussiemion.github.io/keyboard-layout-demo/)**

Experimente símbolos tipográficos, acentos e mudanças de idioma no navegador,
sem instalação nem conta. Pode escrever com o teclado físico ou clicar nas
teclas no ecrã.

> [!IMPORTANT] **Desative a disposição tipográfica do sistema antes de testar.**
> Pode intercetar <kbd>Alt</kbd> ou <kbd>Caps Lock</kbd> antes de chegarem ao
> navegador. O alerta só aparece após eventos característicos; a sua ausência
> não prova que a disposição esteja inativa.

## Primeiros caracteres

Numa sequência, solte <kbd>Alt</kbd> antes da tecla seguinte. O sinal + indica
teclas premidas em simultâneo. No macOS, use <kbd>Option</kbd> em vez de
<kbd>Alt</kbd>. As letras identificam posições físicas, mesmo quando as legendas
mudam com o idioma.

| Prima                                                      | Resultado |   Modo   |
| ---------------------------------------------------------- | :-------: | :------: |
| <kbd>Alt</kbd>, depois <kbd>C</kbd>                        |    `©`    | **`M1`** |
| <kbd>Alt</kbd>, depois <kbd>Alt</kbd>, depois <kbd>C</kbd> |    `¢`    | **`M2`** |
| <kbd>Alt</kbd> + <kbd>-</kbd>                              |    `—`    | **`M0`** |
| <kbd>Alt</kbd> + <kbd>/</kbd>                              |    `…`    | **`M0`** |
| <kbd>Alt</kbd> + <kbd>,</kbd>                              |    `«`    | **`M0`** |
| <kbd>Alt</kbd> + <kbd>.</kbd>                              |    `»`    | **`M0`** |

**`M0`** é a escrita normal; **`M1`** e **`M2`** escolhem uma camada de símbolos
para a próxima entrada. Não existe limite de tempo entre as teclas.
<kbd>Esc</kbd> cancela o símbolo ou acento pendente. Também pode selecionar
`M0`/`M1`/`M2` acima do teclado.

> [!TIP] O menu inclui uma **visita guiada** com pequenos exercícios. Se já
> conhecer a [disposição de Birman](https://ilyabirman.ru/typography-layout/),
> os três exercícios introdutórios são omitidos. O teste final com todos os
> símbolos é opcional. O botão do livro abre a folha de referência.

## Acentos

O português usa a disposição de referência de Portugal. Mudar a plataforma
visual não a substitui por variantes nacionais de Windows ou macOS.

Escreva e solte uma letra; depois prima e solte <kbd>Shift</kbd> para percorrer
as variantes: `a → á → à → â → ã → a`, `c → ç → c`, `o → ó → ô → õ → o`.
Funcionam ambos os <kbd>Shift</kbd>, físicos e no ecrã.

<kbd>Alt</kbd>, <kbd>Alt</kbd> e a posição física de <kbd>/</kbd> preparam um
acento agudo para a letra seguinte.

## Idiomas e definições

| Posição  | Prima                               | Resultado                              |
| :------: | ----------------------------------- | -------------------------------------- |
| **`S0`** | <kbd>Caps Lock</kbd>                | Alternar entre dois idiomas principais |
| **`S1`** | <kbd>Caps Lock</kbd> + <kbd>J</kbd> | Idioma atribuído 1                     |
| **`S2`** | <kbd>Caps Lock</kbd> + <kbd>K</kbd> | Idioma atribuído 2                     |
| **`S3`** | <kbd>Caps Lock</kbd> + <kbd>L</kbd> | Idioma atribuído 3                     |
| **`S4`** | <kbd>Caps Lock</kbd> + <kbd>;</kbd> | Idioma atribuído 4                     |

Atribua os seis idiomas em **Menu → Definições** e **guarde**. As duas opções de
**`S0`** devem ser diferentes; as restantes podem repetir-se. Escolher o idioma
da **interface** também escolhe o seu teclado. O seletor **acima do teclado**
muda apenas o teclado, sem alterar o idioma do sistema ou o texto.

Mantenha ambos os <kbd>Ctrl</kbd> e solte-os para ativar ou desativar a
tipografia. <kbd>Caps Lock</kbd> continua a mudar de idioma.

## Pesquisa e aparência

A lupa, <kbd>Ctrl</kbd> + <kbd>F</kbd> ou <kbd>Ctrl</kbd> + <kbd>K</kbd> abrem a
pesquisa local. Procure por nome, carácter, código como `U+0024`, idioma ou
país. A pesquisa abrange os catorze idiomas e tolera pequenos erros de escrita.

O menu oferece temas claro e escuro. Linux/Windows/macOS muda o aspeto do
teclado, não a disposição do sistema.

A aplicação não guarda nem transmite o texto de prática ou as pesquisas. As
preferências ficam no navegador; os tipos de letra são fornecidos com o site.
