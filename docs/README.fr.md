## Premiers caractères

**Puis** signifie appuyer et relâcher avant la touche suivante ; **+**,
maintenir ensemble. Les touches indiquent les positions physiques US QWERTY. Sur
macOS, <kbd>Alt</kbd> correspond à <kbd>Option</kbd>.

| Appuyez                                                | Résultat |   Mode   |
| ------------------------------------------------------ | :------: | :------: |
| <kbd>Alt</kbd>, puis <kbd>C</kbd>                      |   `©`    | **`M1`** |
| <kbd>Alt</kbd>, puis <kbd>Alt</kbd>, puis <kbd>C</kbd> |   `¢`    | **`M2`** |
| <kbd>Alt</kbd> + <kbd>-</kbd>                          |   `—`    | **`M0`** |
| <kbd>Alt</kbd> + <kbd>/</kbd>                          |   `…`    | **`M0`** |
| <kbd>Alt</kbd> + <kbd>,</kbd>                          |   `«`    | **`M0`** |
| <kbd>Alt</kbd> + <kbd>.</kbd>                          |   `»`    | **`M0`** |

**`S` — Switcher**: commutateur de langue (**`S0`–`S4`**). **`M` — Modifier**:
modificateur du mode de saisie (**`M0`–`M2`**).

**`M0`** est la saisie ordinaire. **`M1`** et **`M2`** sélectionnent une couche
de symboles pour la prochaine saisie. Aucun délai entre les pressions.
<kbd>Esc</kbd> annule le symbole ou l’accent en attente.

> [!TIP]
>
> **Menu → Visite guidée** propose de courts exercices. L’introduction à
> [Birman](https://ilyabirman.ru/typography-layout/) et le test final sont
> facultatifs. Le bouton représentant un livre ouvre l’aide-mémoire.

## Accents

La carte française utilise l’AZERTY traditionnel. Après une lettre relâchée,
appuyez puis relâchez <kbd>Shift</kbd> pour parcourir ses variantes :
`e → é → è → ê → ë → e`, `c → ç → c`. Maintenu avec la lettre, <kbd>Shift</kbd>
garde son rôle habituel.

Pour un accent aigu : <kbd>Alt</kbd>, <kbd>Alt</kbd>, <kbd>/</kbd>, puis la
voyelle. Le niqqud hébreu utilise <kbd>Alt</kbd> droit ; les voyelles arabes
utilisent <kbd>Shift</kbd> maintenu. Ces langues n’ont pas de cycle après la
lettre.

## Langues et réglages

| Emplacement | Appuyez                             | Résultat                                |
| :---------: | ----------------------------------- | --------------------------------------- |
|  **`S0`**   | <kbd>Caps Lock</kbd>                | Alterner entre deux langues principales |
|  **`S1`**   | <kbd>Caps Lock</kbd> + <kbd>J</kbd> | Langue attribuée 1                      |
|  **`S2`**   | <kbd>Caps Lock</kbd> + <kbd>K</kbd> | Langue attribuée 2                      |
|  **`S3`**   | <kbd>Caps Lock</kbd> + <kbd>L</kbd> | Langue attribuée 3                      |
|  **`S4`**   | <kbd>Caps Lock</kbd> + <kbd>;</kbd> | Langue attribuée 4                      |

Dans **Menu → Réglages**, attribuez les six langues puis **enregistrez**. Les
deux choix de **`S0`** doivent être différents ; les autres peuvent se répéter.

Changer la langue de **l’interface** choisit aussi sa carte de clavier. Le
sélecteur **au-dessus du clavier** ne change que le clavier. Ni la langue du
système ni le texte existant ne changent.

Maintenez les deux <kbd>Ctrl</kbd> puis relâchez-les pour activer ou désactiver
la typographie. <kbd>Caps Lock</kbd> continue de changer de langue.

## Recherche et apparence

La loupe, <kbd>Ctrl</kbd> + <kbd>F</kbd> ouvrent la recherche. Saisissez un nom,
un symbole, `U+0024`, une langue ou un pays. Les petites fautes sont tolérées ;
chaque fiche explique la saisie et l’usage.

Le menu propose les thèmes clair et sombre. Linux/Windows/macOS change
l’apparence du clavier, pas la disposition du système.

L’application n’enregistre ni ne transmet le texte ou les recherches. Les
préférences restent dans le navigateur ; les polices sont fournies avec le site.
