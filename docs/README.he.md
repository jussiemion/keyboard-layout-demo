## טיפוגרפיה לעבודה שלך

### לכותבים ולעורכים

תרגלו מקף ארוך —, מירכאות «», “”, „“ ורווחים קשיחים ללא קודי Alt. בהדגמה Alt עם
מקש המינוס מפיק — ללא Alt+0151. אתם בוחרים את המירכאות; הן אינן מוחלפות
אוטומטית.

### למעצבים גרפיים, מעצבי אתרים ומעצבי UI/UX

מצאו והעתיקו ©, ®, ™ וגם $, €, £, ¥, ¢ למחירים, טקסטי ממשק ועיצובים רב־לשוניים.
הדביקו סימנים מהמדריך ב־Figma או בעורך. ההדגמה אינה תוסף ל־Figma.

### לדוברי שפות ולמתרגמים

תרגלו ä, ö, ü בגרמנית ו־é, è, ç בצרפתית במקלדת רגילה. הקלידו אות ואז לחצו
<kbd>Shift</kbd> למעבר בין החלופות בשפה שנבחרה. אין צורך בחבילות שפה של מערכת
ההפעלה כדי לנסות את ההדגמה.

14 שפות ממשק ו־24 אפשרויות מקלדת, כולל גרסאות אזוריות. ההקלדה פועלת בהדגמה;
יישומים אחרים דורשים התקנה נפרדת במערכת. התמיכה בשפות שאינן אירופיות ניסיונית.

## שאלות נפוצות

### איך מקלידים סימנים מיוחדים בלי קודי Alt?

במיפוי ברירת המחדל, <kbd>Alt</kbd> + מינוס מקליד — ו־<kbd>Alt</kbd> + / מקליד ….
כדי להקליד ©, לחצו על <kbd>Alt</kbd> ושחררו, ואז לחצו על C. ב־macOS השתמשו
ב־<kbd>Option</kbd>. מיקומי המקשים הם לפי US QWERTY; רצפים נוספים מופיעים
במדריך.

### איך מקלידים במהירות אותיות עם סימנים דיאקריטיים?

בחרו שפת מקלדת, הקלידו אות בסיס ושחררו את המקש. בשפות התומכות במחזור, לחיצות
נפרדות על <kbd>Shift</kbd> עוברות בין הגרסאות: בגרמנית u → ü ובצרפתית e → é → è
→ ê → ë. האפשרויות תלויות בשפה; ניקוד בעברית מוזן באמצעות <kbd>Alt</kbd> הימני.

### איך מוסיפים סימן הטעמה מעל אות?

במיפוי ברירת המחדל, לחצו על <kbd>Alt</kbd> ושחררו פעמיים, אחר כך לחצו על /
במיקום US QWERTY, ואז הקלידו תנועה: למשל ברוסית а → а́. הלחיצות הן בזו אחר זו ולא
יחד. בוחרים את הסימן לפני האות. ב־macOS השתמשו ב־<kbd>Option</kbd>;
<kbd>Esc</kbd> מבטל את הסימן הממתין. זהו סימן הטעמה, לא ניקוד עברי.

### במה פריסת Yushkevich שונה מפריסת [Birman](https://ilyabirman.ru/typography-layout/) בהקלדת אותיות זרות?

היא מאפשרת לעבור בין גרסאות האות האחרונה באמצעות <kbd>Shift</kbd> ולהחליף בין
שפות שהוגדרו בהדגמה. גם פריסת [Birman](https://ilyabirman.ru/typography-layout/)
תומכת בסימנים דיאקריטיים; מפת הסימנים שלה היא הבסיס לפרויקט. הבחירה תלויה
בהרגלים ובשפות שבהן משתמשים.

### איך מקלידים €, © או ™ לעיצוב?

חפשו בהדגמה לפי שם הסימן או לפי הסימן עצמו. המדריך מסביר את השימוש ואת רצף
ההקלדה. אפשר להעתיק את הסימן ל־Figma, לעורך טקסט או למצגת.

### אפשר לנסות את הפריסה בלי התקנה?

כן. פתחו את ההדגמה בדפדפן והשתמשו במקלדת פיזית או במקלדת שעל המסך. אין צורך
בהתקנה או בחבילות שפה למערכת. ההקלדה פועלת רק בתוך הדף ואינה משנה את המקלדת
ביישומים אחרים.

## הסימנים הראשונים

ברצף הקשות יש לשחרר את <kbd dir="ltr">Alt</kbd> לפני המקש הבא. הסימן + מציין
מקשים שמחזיקים יחד. ב־macOS משתמשים ב־<kbd dir="ltr">Option</kbd> במקום
<kbd dir="ltr">Alt</kbd>. שמות האותיות מציינים מיקומים פיזיים במקלדת, גם כאשר
הכיתוב על המקשים משתנה לפי השפה.

| לחצו                                                                                                      |           תוצאה            |   מצב    |
| --------------------------------------------------------------------------------------------------------- | :------------------------: | :------: |
| <span dir="ltr"><kbd dir="ltr">Alt</kbd>, ואז <kbd dir="ltr">C</kbd></span>                               | <span dir="ltr">`©`</span> | **`M1`** |
| <span dir="ltr"><kbd dir="ltr">Alt</kbd>, ואז <kbd dir="ltr">Alt</kbd>, ואז <kbd dir="ltr">C</kbd></span> | <span dir="ltr">`¢`</span> | **`M2`** |
| <span dir="ltr"><kbd dir="ltr">Alt</kbd> + <kbd dir="ltr">-</kbd></span>                                  | <span dir="ltr">`—`</span> | **`M0`** |
| <span dir="ltr"><kbd dir="ltr">Alt</kbd> + <kbd dir="ltr">/</kbd></span>                                  | <span dir="ltr">`…`</span> | **`M0`** |
| <span dir="ltr"><kbd dir="ltr">Alt</kbd> + <kbd dir="ltr">,</kbd></span>                                  | <span dir="ltr">`«`</span> | **`M0`** |
| <span dir="ltr"><kbd dir="ltr">Alt</kbd> + <kbd dir="ltr">.</kbd></span>                                  | <span dir="ltr">`»`</span> | **`M0`** |

**`S` — Switcher**: מחליף שפה (**`S0`–`S4`**). **`M` — Modifier**: מקש משנה
להחלפת מצב ההקלדה (**`M0`–`M2`**).

**`M0`** הוא הקלדה רגילה; **`M1`** ו־**`M2`** בוחרים שכבת סמלים להזנה הבאה. אין
מגבלת זמן בין ההקשות. <kbd dir="ltr">Esc</kbd> מבטל סימן או סימן דיאקריטי
שממתינים להזנה. אפשר לבחור גם במצבים `M0`/`M1`/`M2` מעל המקלדת.

## אותיות וניקוד

המפה העברית מבוססת על מפת הייחוס הישראלית <span dir="ltr">XKB il(basic)</span>.
שדה ההקלדה תומך בכתיבה מימין לשמאל.

<kbd dir="ltr">Alt</kbd> ימני, כלומר <kbd dir="ltr">AltGr</kbd>, משמש לניקוד
ולסימנים לאומיים. את הניקוד מזינים אחרי האות.

לעברית ולערבית אין מחזור באמצעות <kbd dir="ltr">Shift</kbd> אחרי אות. בערבית
מזינים את סימני התנועה באמצעות <kbd dir="ltr">Shift</kbd> מוחזק.

## שפות והגדרות

|  מיקום   | לחצו                                                                           | תוצאה                     |
| :------: | ------------------------------------------------------------------------------ | ------------------------- |
| **`S0`** | <kbd dir="ltr">Caps Lock</kbd>                                                 | מעבר בין שתי שפות עיקריות |
| **`S1`** | <span dir="ltr"><kbd dir="ltr">Caps Lock</kbd> + <kbd dir="ltr">J</kbd></span> | שפה שהוקצתה 1             |
| **`S2`** | <span dir="ltr"><kbd dir="ltr">Caps Lock</kbd> + <kbd dir="ltr">K</kbd></span> | שפה שהוקצתה 2             |
| **`S3`** | <span dir="ltr"><kbd dir="ltr">Caps Lock</kbd> + <kbd dir="ltr">L</kbd></span> | שפה שהוקצתה 3             |
| **`S4`** | <span dir="ltr"><kbd dir="ltr">Caps Lock</kbd> + <kbd dir="ltr">;</kbd></span> | שפה שהוקצתה 4             |

הקצו שש שפות דרך **תפריט ← הגדרות** ו**שמרו**. שתי האפשרויות של **`S0`** חייבות
להיות שונות; האחרות יכולות לחזור. בחירת שפת **הממשק** בוחרת גם את המקלדת
המתאימה. הבורר **מעל המקלדת** משנה רק את המקלדת, ללא שינוי שפת המערכת או הטקסט
הקיים.

החזיקו את שני מקשי <kbd dir="ltr">Ctrl</kbd> ושחררו להפעלה או לכיבוי של
הטיפוגרפיה. <kbd dir="ltr">Caps Lock</kbd> ממשיך להחליף שפות.

עם שפת הבסיס.

## חיפוש ומראה

זכוכית המגדלת, <kbd dir="ltr">Ctrl</kbd> + <kbd dir="ltr">F</kbd> פותחים חיפוש
מקומי. אפשר לחפש לפי שם, סימן, קוד כמו <span dir="ltr">`U+0024`</span>, שפה או
מדינה. החיפוש מכסה את כל 14 השפות וסובל שגיאות הקלדה קטנות.

- **חיפוש סמל:** <kbd dir="ltr">Ctrl</kbd> + <kbd dir="ltr">F</kbd> /
  <kbd dir="ltr">Caps Lock</kbd> + <kbd dir="ltr">F</kbd>.
- **דף עזר:** <kbd dir="ltr">Ctrl</kbd> + <kbd dir="ltr">H</kbd> /
  <kbd dir="ltr">Caps Lock</kbd> + <kbd dir="ltr">H</kbd>.

בתפריט אפשר לבחור מראה בהיר או כהה. Linux/Windows/macOS משנה את מראה המקלדת, לא
את פריסת המערכת.

היישום אינו שומר או שולח את טקסט התרגול או את החיפושים. ההעדפות נשמרות בדפדפן.
הגופנים כלולים באתר.
